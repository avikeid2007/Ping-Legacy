Features

Everything you need to diagnose and monitor your network

🌐

Live Ping Testing

Continuous ICMP ping to any host with real-time results and statistics.

🎯

Multi-Ping Monitor NEW

Ping up to 8 targets simultaneously with a live dashboard and real-time updates.

📈

Real-time Graph

Visual latency chart showing ping trends over time with gradient visualization.

🗺️

Traceroute

Trace hop-by-hop path to any destination with timing and host resolution.

🔐

Port Scanner

Check open ports on any host with customizable port ranges.

🚀

Speed Test

Test your download and upload speeds with latency measurement.

📜

Unified History NEW

View all past operations with filtering, search, and export capabilities.

📉

Network Statistics

Track network data usage, connection info, and daily averages.

🔍

DNS Lookup

Resolve hostnames and display IPv4, IPv6, and canonical records.

⏰

Scheduled Pings

Monitor hosts at regular intervals with background notifications.

🌙

Dark/Light Theme

System-aware theming with beautiful modern UI design.

🗑️

Auto Cleanup NEW

Configurable history retention with automatic cleanup of old records.
